# Sweet Bliss - AI Bakery Website 🍰

A modern bakery website created using Lovable AI as part of the Generative AI assignment at Superior University, Lahore.

### 📖 About The Project
This project is about building a complete bakery business website using Generative AI. It was created with Lovable AI to learn prompt engineering and AI-assisted development.

### ✨ Features
- Home page with banner and call-to-action
- About Us section
- Menu with cakes, pastries, and breads
- Contact form
- Fully responsive design for mobile and desktop

### 🛠️ Built With
- Lovable AI (Generative AI tool)
- HTML, CSS, JavaScript
- GitHub
